# **Goal**

Create a "Personal AI Agent" web application.  
Think of it as a consumer-facing version of applications like OpenClaw or Hermes Agent.  
Do not simply host an existing OpenClaw or Hermes Agent; build an original one from scratch.

# **Mandatory Requirements**

## **Functional Requirements**

- Ability to provide instructions to any LLM in a conversational format and receive responses.  
- Ability to retrieve reports that capture deeper insights than simple conversations by using LLM-based long-term reasoning and data exploration (Deep Research).  
- Users can create, log in to, log out of, and delete their own accounts.  
- Ability to provide inputs other than text (voice, files, Google Drive integration, etc.).  
- Include 2 or more original additional features:  
  - For example,  
    - External service integration.  
    - Periodic autonomous execution (Heart Beat).  
    - Long-term context memory and output based on it.  
    - Etc.

## **Non-Functional Requirements**

- The frontend can be used as a web application.  
- The application can only be accessed by specific users, groups, or environments.  
- Define the expected number of users for the entire service and design the system on the assumption that it will be production-ready. 

## **Technical Requirements**

- Use Python for the backend.  
- Use React or a React-based framework for the frontend.  
- Use Google Cloud for infrastructure and manage it using IaC.  
- Perform continuous quality assurance via CI and automate deployment via CD.


# **Optional Requirements**

Once the mandatory requirements are met, feel free to add features or improve the UX based on your experience with existing services.  
Innovations in the development process, not just within the service itself, are also highly welcome.

# **Report**

Based on the application and infrastructure we created, please prepare a report including the following:

- Service overview.  
- Technology and architecture adopted for the entire service.  
- Additional features and ingenuity not included in the mandatory requirements.  
- Parts We deliberately omitted and the implementation policy if they were to be implemented.  
- System quality assurance and testing strategy.  
- Monitoring and logging design.  
- Security measures.

Each content should include points where i was creative and the reasons for my choices in each section.  
If there are any other points I would like to highlight, please summarize and add them as an appendix.

# **Deliverables**

- URL of the created web application.  
- Report
- Source code (GitHub).  
  - Private repositories are acceptable.  
  - Please add permissions for employees after submission is complete.
