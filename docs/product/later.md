# Later

A later version lets one account have several named bots. One email still holds one account.

A later version lets the assistant name a new thread.

A later version searches threads and edits an earlier message.

A later version lets the model write new code and run it in a sandbox.

A later version allows a repeated form when code matches the site, the form, the allowed fields, and an expiry. The model does not decide that two forms are the same form.

A later integration is another row: a connection on the account, a secret in Cloud KMS, and one or more tools.

A later version exports an account's data.

A later version groups accounts in an organization.
