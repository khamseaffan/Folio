# Control

The person changes a thread, a knowledge file, an ability, a report, a task file, and a schedule by telling the agent in the chat. The agent creates, updates, and deletes those records.

The person uses these controls directly: sign-in, ending a session, the display name, deleting the account, uploading a file, downloading a file or a report, picking a Drive file, disconnecting Drive, stopping a reply that is streaming, and confirming a send on a website. The agent does not confirm a send.

A schedule exists because the person said in the chat when the work should happen. The agent creates it, updates it, and deletes it.
