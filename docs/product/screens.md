# Screens

The site opens on one public page. The person signs in from that page.

Day one has chat, reports, files, a profile panel, and settings.

Chat is the thread list and the open thread. The thread name shows a status mark while a run is working or waiting. A waiting question appears in that thread. Inside the thread the person sees the assistant's messages.

Reports opens from the account block beside Settings and takes the place of the chat. It lists the account's reports, newest first, each with its name, question, and time, and shows the newest one at first. A report shows its name, its question, its text, how the research stopped, and its numbered sources. A web source is a link that opens in a new tab, and each source has a line on what it was used for. A Download link saves the report as a Markdown file. The list updates when a chat turn ends or the open thread gets a new message, so a finished report appears without a reload. Naming, renaming, and deleting stay in the chat.

Files lists the account's uploads and task files. The person can upload, download, and see the byte count. Deleting stays in the chat.

The profile panel opens from the top of the chat. It shows the knowledge files, the abilities, and the upcoming schedules. The person reads them there. Creating, changing, and deleting them stays in the chat.

Settings holds the display name, the sessions, the integrations, and deleting the account. The token totals are shown there. `khamseaffan@gmail.com` also selects the platform provider and model there. Another account does not see that control.

In a wide window the thread and the profile panel sit side by side. A narrow window remains usable.

The interface is English.
